# 本工作区约定

DSH Go 源码树。Android 端是 Flutter + 内嵌 proot Linux 容器，引擎是 DeepSeek Harness。

## 输出风格

- 中文回答，直接给结果。第一行就是内容，不要开场白，不要收尾客套。
- 给代码就给完整文件，不要片段拼凑；给命令就给可整行粘贴的版本。
- 需要解释时放在结果之后，不要放在结果之前。
- 不确定的事实先查证再说，不要用"可能""大概"糊过去。

## 工程约定

- 改文件前先读，改完核对；只改指定范围，无关内容原样保留。
- 生成脚本一律带中文注释，每个函数说明它做什么。
- 提交前自检：路径存在、参数完整、输出可复现。
- 报错就直接贴原始输出，不要转述。
